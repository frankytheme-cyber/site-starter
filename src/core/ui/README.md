# Primitive UI

`Section` (radice di ogni blocco: tono, spaziatura, Container, slot `background`; `as="header"`, `flush` e `sticky` per l'intestazione), `Container`, `Button` (primary, secondary, link), `Img` (wrapper di `<Image>`, alt obbligatorio), `Icon` (SVG inline dagli alias di `core/icons.ts`, sm/md/lg, `label` per le icone non decorative).
Nessun contenuto proprio, solo struttura e classi semantiche.
