# Gestione del flusso Paperclip

**In pausa dal 2026-10-20:** si lavora con un agente solo, Claude Code o Codex (`AGENTS.md`, sezione «Lavorare con Claude Code o Codex»). Questi documenti restano per quando la squadra riparte.

La [procedura operativa](skill/modelli-task/references/paperclip.md) copre consegne,
attività rinviate, diagnosi degli arresti e propagazione degli aggiornamenti.
È inclusa anche nella skill attiva `modelli-task`, per i siti ancora su versioni precedenti.

La correzione locale del runtime e il relativo test sono in [paperclip-runtime](paperclip-runtime/).
