# Forme

Un file per forma con un blocco `[data-shape="nome"]` che imposta `--box-radius` (card e riquadri, `rounded-box`) e `--button-radius` (pulsanti, `rounded-button`).
Una forma nuova va importata in `base.css` e aggiunta a `presets.ts`, con la sua scheda `<nome>.meta.ts` (`PresetMeta`: nome, mood, settori a cui si adatta).
